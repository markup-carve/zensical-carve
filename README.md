# zensical-carve

Zensical integration for Carve blocks and `.crv` pages, using carve-lang 0.1.11 or later. It renders complete pages before the Zensical build. Read the [Carve documentation](https://markup-carve.github.io/carve/) for the language syntax.

## Install

```sh
pip install zensical-carve
```

## Usage

```sh
zensical-carve prepare
zensical build
```
